# The Dev News

Blog responsivo desenvolvido para o desafio de HTML e CSS da DNC.

## Sobre

Página web de blog com design moderno e totalmente responsivo, adaptável a diferentes tamanhos de tela desde dispositivos móveis até monitores ultrawide. Os estilos utilizam unidades relativas (rem/em) e técnicas modernas de layout como CSS Grid e Flexbox.

## Tecnologias

- HTML5
- CSS3
- Google Fonts (Montserrat)

## Como usar

Clone o repositório:

```bash
git clone https://github.com/lucas-gonzales/RID99751_Desafio_Desenvolvendo_um_Blog_Responsivo.git
cd RID99751_Desafio_Desenvolvendo_um_Blog_Responsivo
```

Abra o arquivo `index.html` no navegador.

## Layout

O design foi baseado no protótipo do [Figma](https://www.figma.com/design/4JJ2iYIuL7FW1AQo6JYwl8).

**Desktop:** Layout em grid com posts à esquerda e sidebar à direita

**Tablet:** Posts em grid 2 colunas, sidebar horizontal abaixo

**Mobile:** Layout em coluna única, elementos empilhados verticalmente

## Funcionalidades

- Layout responsivo com 4 breakpoints (mobile, tablet, desktop, ultrawide)
- Semântica HTML5 com tags apropriadas (header, nav, main, article, aside, footer)
- Unidades de medida relativas (rem/em) para escalabilidade
- CSS Grid e Flexbox para layouts flexíveis
- Acessibilidade com skip-link e ARIA labels
